# รายชื่อพระสูตรมหายานจาก DSBC พร้อมโน้ตย่อ

รายการพระสูตรมหายานจาก [Digital Sanskrit Buddhist Canon (DSBC)](https://www.dsbcproject.org/canon-text/list/6)

| ลำดับ | ชื่อพระสูตร (สันสกฤต) | ชื่อไทย (แปลคร่าวๆ) | โน้ตย่อ |
|-------|----------------------|---------------------|----------|
| 1 | Ajitasenavyākaraṇam | คำทำนายของอชิตเสน | พระสูตรเกี่ยวกับการทำนายของพระอชิตเสน |
| 2 | Aparimitāyuḥ nāma mahāyāna sūtram | พระสูตรว่าด้วยอายุไพศาล | พระสูตรเกี่ยวกับพระอมิตาภุทธและอายุยืน |
| 3 | Arthaviniścayasūtram | พระสูตรแห่งการวิเคราะห์อรรถะ | พระสูตรปรัชญาเกี่ยวกับการวิเคราะห์ความหมาย |
| 4 | Ārya ṃaitreya-vyākaraṇaṃ | คำทำนายของพระศรีอาริย์ | พระสูตรเกี่ยวกับการทำนายการตรัสรู้ของพระศรีอาริย์ |
| 5 | Āryānityatā sūtram | พระสูตรแห่งความไม่เที่ยง | พระสูตรสอนหลักอนิจจัง (ความไม่เที่ยง) |
| 6 | Āryapratītyasamutpādo nāma mahāyānasūtram | พระสูตรว่าด้วยปฏิจจสมุปบาท | พระสูตรหลักสอนปฏิจจสมุปบาท (เหตุผลเกิด) |
| 7 | Āryarāṣṭrapālaparipṛcchā nāma mahāyānasūtram | พระสูตรแห่งการถามของผู้ปกป้องรัฐ | พระสูตรเกี่ยวกับการปกป้องและธรรมศาสตร์การปกครอง |
| 8 | Āryasāgaranāgarājaparipṛcchā nāma mahāyānasūtram | พระสูตรแห่งการถามของพญานาคราชสาคร | พระสูตรสนทนากับพญานาค |
| 9 | Āryasaṃghāṭa sūtram | พระสูตรสังฆาฏิ | พระสูตรเกี่ยวกับผ้าสังฆาฏิและวัตถุสงฆ์ |
| 10 | Āryasarvabuddhaviṣayāvatārajñānālokālaṃkāranāma mahāyānasūtram | พระสูตรแห่งแสงสว่างแห่งความรู้ทั่วถึงในพระพุทธเจ้าทั้งหมด | พระสูตรปรัชญาเกี่ยวกับความรู้และการตรัสรู้ |
| 11 | Āryatriratnānusmṛtisūtram | พระสูตรระลึกถึงไตรรัตน์ | พระสูตรสอนการระลึกถึงพระพุทธ พระธรรม พระสงฆ์ |
| 12 | Āryatriskandha sūtram | พระสูตรสามขันธ์ | พระสูตรสอนธรรมในสามหมวด (จริยธรรม จิตใจ ปัญญา) |
| 13 | Āryavimalakīrtinirdeśo nāma mahāyānasūtram | พระสูตรวิมลกีรตินิเทศ | พระสูตรดังสอนปัญญาและอุบายวิธี ผ่านท่านวิมลกีรติ |
| 14 | Bhaiṣajyaguruvaidūryaprabharājasūtram | พระสูตรพระภัยชัชยคุรุ | พระสูตรพระเทพแห่งการรักษา (พระหมอแสงแก้ว) |
| 15 | Bhavasaṅkrāntisūtram | พระสูตรการเกิดใหม่ | พระสูตรเกี่ยวกับการเวียนว่ายตายเกิดและการเปลี่ยนภพ |
| 16 | catuṣpariṣat sūtram | พระสูตรสหบดีสี่ฝ่าย | พระสูตรเกี่ยวกับสี่ฝ่าย (ภิกษุ ภิกษุณี อุบาสก อุบาสิกา) |
| 17 | Daśabhūmikasūtram | พระสูตรสิบภูมิ | พระสูตรสอนเส้นทางโพธิสัตว์สิบภูมิ |
| 18 | Gaṇḍavyūha sūtram | พระสูตรคัณฑวยูหะ | พระสูตรมหายานสำคัญ เรื่องการเดินทางของสุธนกุมาร |
| 19 | Guṇakāraṇḍavyūha sūtram | พระสูตรกุณการเณยูหะ | พระสูตรเกี่ยวกับคุณวิเศษและเครื่องประดับ |
| 20 | Kāraṇḍavyūhaḥ | พระสูตรการเณยูหะ | พระสูตรสรรเสริญพระอวโลกิเตศวร |
| 21 | Karuṇāpuṇḍarīka sūtram | พระสูตรดอกบัวแห่งกรุณา | พระสูตรสอนพระกรุณาและเมตตา |
| 22 | Kāśyapaparivarta sūtram | พระสูตรปริวารต์ของพระกัสสป | พระสูตรเกี่ยวกับพระกัสสปและคำสอนของท่าน |
| 23 | Lalitavistaraḥ | พระสูตรลลิตวิสตระ | พระสูตรมหายานสำคัญ เรื่องประวัติพระพุทธเจ้าอย่างละเอียด |
| 24 | Madhyamaka-śālistambasūtram | พระสูตรเสาธรรมมัธยมิก | พระสูตรสอนธรรมสายมัชฌิมาปฏิบัติ (ทางสายกลาง) |
| 25 | Mahāmegha sūtram | พระสูตรเมฆใหญ่ | พระสูตรเกี่ยวกับเมฆและฝนเป็นสัญลักษณ์ธรรม |
| 26 | Mahāparinirvāṇa sūtram | พระสูตรปรินิพพานใหญ่ | พระสูตรเหตุการณ์สุดท้ายของพระพุทธเจ้า |
| 27 | Mahāvadānasūtram | พระสูตรมหาวาทาน | พระสูตรรวมเรื่องราวอัศจรรย์ในพุทธประวัติ |
| 28 | Megha sūtram | พระสูตรเมฆ | พระสูตรเกี่ยวกับสัญลักษณ์ของเมฆในธรรม |
| 29 | Nairātmyaparipṛcchā nāma mahāyānasūtram | พระสูตรถามเรื่องอนัตตา | พระสูตรสอนปรัชญาอนัตตา (ไม่มีตัวตน) |
| 30 | Pañcarakṣā sūtram | พระสูตรห้ารักษา | พระสูตรเกี่ยวกับพระคาถารักษา 5 องค์ |
| 31 | Saddharmalaṅkāvatārasūtram | พระสูตรประดับธรรมอันดี | พระสูตรเกี่ยวกับการประดับตกแต่งด้วยธรรมอันดี |
| 32 | Saddharmapuṇḍarīkasūtram | พระสูตรสัทธรรมปุณฑรีก | พระสูตรมหายานสำคัญ พระสูตรดอกบัวขาว |
| 33 | Śālistambasūtram | พระสูตรเสาธรรม | พระสูตรสอนธรรมโดยใช้สัญลักษณ์เสา |
| 34 | Samādhirājasūtram | พระสูตรแห่งราชาแห่งสมาธิ | พระสูตรสอนสมาธิขั้นสูง |
| 35 | Sarvatathāgatādhiṣṭhānavyūham sūtram | พระสูตรจักรวาลแห่งพระตถาคตทั้งหมด | พระสูตรปรัชญาเกี่ยวกับพระพุทธเจ้าทั้งหลาย |
| 36 | Sukhāvatīvyūhaḥ (saṃkṣiptamātṛkā) | พระสูตรวัตถุมาลาอันดับสุขาวดี (สังเคราะห์) | พระสูตรอธิบายดินแดนสุขาวดีแบบสรุป |
| 37 | Sukhāvatīvyūhaḥ (vistaramātṛkā) | พระสูตรวัตถุมาลาอันดับสุขาวดี (วิสตาระ) | พระสูตรอธิบายดินแดนสุขาวดีแบบละเอียด |
| 38 | Suvarṇaprabhāsasūtram | พระสูตรสุวรรณประภา | พระสูตรมหายานสำคัญ เรื่องแสงทอง |
| 39 | Vimalakīrtinirdeśa sūtram | พระสูตรวิมลกีรตินิเทศ (อีกชื่อ) | เหมือนกับหมายเลข 13 พระสูตรเดียวกัน |
| 40 | Vinayaviniścaya upāliparipṛcchā | พระสูตรว่าด้วยการตัดสินวินัยโดยพระอุปาลิ | พระสูตรเกี่ยวกับวินัยสงฆ์และการถามตอบ |
| 41 | Saddharmasmṛtyupasthānasūtra | พระสูตรระลึกถึงธรรมอันดี | พระสูตรสอนการระลึกถึงธรรมอันดี |
| 42 | Vajrasattvaniṣpādana Sūtra | พระสูตรการบรรลุเป็นวัชระสัตตะ | พระสูตรเกี่ยวกับการปฏิบัติเพื่อบรรลุเป็นวัชระสัตตะ |
| 43 | Maitreyavyākaraṇa | คำทำนายของพระไมตรียะ | พระสูตรเกี่ยวกับการทำนายการมา ของพระศรีอาริย์ (พระไมตรียะ) |
| 44 | Sarvabuddhaviṣayāvatārajñānālokālaṁkāra nāma mahāyānasūtra | พระสูตรแห่งแสงสว่างแห่งความรู้ทั่วถึงในพระพุทธเจ้าทั้งหมด | คล้ายกับหมายเลข 10 แต่มีการสะกดต่างกันเล็กน้อย |
| 45 | prahāṇapūrakaśatavandanānāma mahāyānasūtram | พระสูตรสรรเสริญด้วยการบูชาร้อยครั้ง | พระสูตรเกี่ยวกับการบูชาและสรรเสริญพระพุทธ |
| 46 | Ajātaśatrukaukṛtyavinodanāsūtra | พระสูตรแสดงความบริสุทธิ์ของพระเจ้าอชาตศัตรุ | พระสูตรเกี่ยวกับพระเจ้าอชาตศัตรุและการล้างปัดเป่าอาชญากรรม |
| 47 | Ajātaśatrukaukṛtyavinodanāsūtra | พระสูตรแสดงความบริสุทธิ์ของพระเจ้าอชาตศัตรุ | ซ้ำกับหมายเลข 46 |
