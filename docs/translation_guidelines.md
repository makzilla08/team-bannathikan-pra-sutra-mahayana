# แนวทางการแปลพระสูตรมหายาน

## หลักการแปล

### 1. ความถูกต้อง
- แปลตามความหมายที่แท้จริงของต้นฉบับ
- รักษาหลักธรรมคำสอนให้ถูกต้อง
- ใช้ศัพท์เทคนิคทางพระพุทธศาสนาอย่างสม่ำเสมอ

### 2. ความชัดเจน
- ใช้ภาษาไทยที่เข้าใจง่าย
- หลีกเลี่ยงคำศัพท์ที่ซับซ้อนเกินไป
- จัดรูปแบบให้อ่านง่าย

### 3. ความสละสลวย
- ใช้ภาษาที่สละสลวยเหมาะสมกับพระสูตร
- รักษาจังหวะและน้ำเสียงของต้นฉบับ
- ปรับภาษาให้เหมาะสมกับผู้อ่านสมัยใหม่

## ขั้นตอนการแปล

### ขั้นตอนที่ 1: เตรียมตัว
1. ศึกษาบริบทของพระสูตร
2. ทำความเข้าใจหลักธรรมที่นำเสนอ
3. รวบรวมศัพท์เฉพาะที่เกี่ยวข้อง

### ขั้นตอนที่ 2: แปลร่าง
1. แปลพระสูตรอย่างละเอียด
2. บันทึกจุดที่สงสัยหรือต้องตรวจสอบ
3. จดบันทึกคำศัพท์เฉพาะที่ใช้

### ขั้นตอนที่ 3: ปรับปรุง
1. ทบทวนการแปล
2. ปรับปรุงภาษาให้สละสลวย
3. ตรวจสอบความสอดคล้องของศัพท์

### ขั้นตอนที่ 4: ตรวจสอบ
1. ส่งให้ผู้ตรวจสอบอ่านทวน
2. แก้ไขตามข้อเสนอแนะ
3. ส่งให้บรรณาธิการอนุมัติ

## รูปแบบไฟล์

### โครงสร้างโฟลเดอร์
```
translations/
└── sutra_{id}/
    ├── original.txt        # ต้นฉบับ
    ├── translation.md      # การแปล
    ├── notes.md           # หมายเหตุ
    ├── metadata.json      # ข้อมูลพระสูตร
    └── chapter_{num}/     # แต่ละบท
        ├── original.txt
        ├── translation.md
        └── notes.md
```

### รูปแบบไฟล์แปล
```markdown
# การแปล: [ชื่อพระสูตร]

## ข้อมูลพระสูตร
- **รหัส**: [sutra_id]
- **ชื่อภาษาสันสกฤต**: [ชื่อสันสกฤต]
- **ชื่อภาษาไทย**: [ชื่อไทย]
- **นักแปล**: [ชื่อนักแปล]
- **วันที่แปล**: [วันที่]

## การแปล

[เนื้อหาการแปล]

## หมายเหตุ
[หมายเหตุประกอบการแปล]
```

## เครื่องมือที่ใช้

### Git
- ใช้สำหรับจัดการเวอร์ชันไฟล์
- สร้าง branch สำหรับการแปลแต่ละเรื่อง
- ทำ Pull Request เพื่อขออนุมัติ

### Python Scripts
- `fetch_sutras.py`: ดึงข้อมูลจาก DSBC
- `translation_manager.py`: จัดการโครงสร้างไฟล์แปล

## การสื่อสาร

### ช่องทาง
- GitHub Issues: สำหรับคำถามและข้อสงสัย
- Pull Requests: สำหรับเสนอการแปล
- การประชุมทีม: ทุกสัปดาห์

### รูปแบบการให้ข้อเสนอแนะ
1. ระบุตำแหน่งที่ต้องแก้ไข
2. อธิบายเหตุผล
3. เสนอแนะทางเลือก

## คุณภาพ

### มาตรฐานการแปล
1. ถูกต้องตามต้นฉบับ
2. เข้าใจง่ายสำหรับผู้อ่านทั่วไป
3. สละสลวยทางภาษา
4. สอดคล้องกับหลักธรรม

### การตรวจสอบ
- ตรวจสอบโดยผู้ตรวจสอบอย่างน้อย 2 คน
- ตรวจสอบความถูกต้องของศัพท์เทคนิค
- ตรวจสอบรูปแบบและเครื่องหมายวรรคตอน
