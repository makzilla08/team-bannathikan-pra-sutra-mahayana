## ขั้นตอนที่ 1: เตรียมข้อมูลพระสูตร

### 1.1 เลือกพระสูตรที่จะแปล
พระสูตรที่สำคัญ (แปลก่อน):
1. ปรมิตาอุตตรशัสตรสูตร (book/68)
2. สัทธรรมปุณฑรีกสูตร (book/54)
3. ลลิตวิสตระสูตร (book/45)
4. วิมลกีรตินิเทศสูตร (book/35)
5. ทศภูมิกสูตร (book/39)

### 1.2 ดึงข้อมูลต้นฉบับ
1. เข้าไปที่: `https://www.dsbcproject.org/canon-text/book/{id}`
2. คัดลอกเนื้อหา Romanized text
3. บันทึกในไฟล์ `translations/sutra_{id}/original.txt`

### 1.3 ศึกษาพระสูตร
- อ่านต้นฉบับให้เข้าใจบริบท
- หาข้อมูลประวัติพระสูตร
- ระบุหลักธรรมสำคัญ
- รวบรวมคำศัพท์เฉพาะ

### 1.4 บันทึกข้อมูลเริ่มต้น
แก้ไขไฟล์ `metadata.json`:
```json
{
  "sutra_id": "54",
  "title": "Saddharmapuṇḍarīkasūtram",
  "title_thai": "สัทธรรมปุณฑรีกสูตร",
  "translator": "ชื่อนักแปล",
  "start_date": "2026-03-18",
  "status": "in_progress"
}
```

## ขั้นตอนที่ 2: การแปล

### 2.1 แปลร่าง (Rough Draft)
**ระยะเวลา**: 1-2 สัปดาห์สำหรับพระสูตรขนาดเล็ก

1. **แปลทีละบรรทัด**
   - อ่านต้นฉบับ 1-2 วรรค
   - แปลเป็นภาษาไทย
   - บันทึกในไฟล์ `translation.md`

2. **บันทึกจุดสงสัย**
   - ทำเครื่องหมาย `[?]` สำหรับจุดที่ไม่แน่ใจ
   - บันทึกใน `notes.md`

3. **รวบรวมศัพท์เฉพาะ**
   - สร้างตารางศัพท์ใน `glossary.md`
   - บันทึกคำศัพท์ที่ใช้

### 2.2 ตัวอย่างรูปแบบการแปล
```markdown
## การแปล

### บรรทัดที่ 1-5
**ต้นฉบับ**: evaṃ mayā śrutaṃ ekasmiṃ samaye...

**การแปล**: ดังเราได้สดับมา ในกาลครั้งหนึ่ง...

**หมายเหตุ**: 
- `evaṃ mayā śrutaṃ` = ดังเราได้สดับมา (คำขึ้นต้นพระสูตร)
```

### 2.3 ปรับปรุงภาษา
1. **อ่านทวนการแปล**
   - อ่านด้วยเสียงดัง
   - ตรวจความลื่นไหลของภาษา
   - แก้ไขประโยคที่แข็งกระด้าง

2. **ปรับปรุงศัพท์**
   - ใช้ศัพท์ที่สอดคล้องกัน
   - เพิ่มคำอธิบายเมื่อจำเป็น
   - ตรวจสอบกับพจนานุกรม

3. **จัดรูปแบบ**
   - ใช้เครื่องหมายวรรคตอนถูกต้อง
   - จัดย่อหน้าให้อ่านง่าย
   - เพิ่มหัวข้อย่อยเมื่อเหมาะสม

## ขั้นตอนที่ 3: การตรวจสอบ

### 3.1 ตรวจสอบเบื้องต้น (Self-Review)
**ระยะเวลา**: 2-3 วัน

- [ ] แปลครบถ้วนทุกบรรทัด
- [ ] ไม่มีข้อความตกหล่น
- [ ] ศัพท์ใช้อย่างสม่ำเสมอ
- [ ] รูปแบบถูกต้อง

### 3.2 ตรวจสอบโดยผู้อื่น (Peer Review)
**ระยะเวลา**: 1 สัปดาห์

ผู้ตรวจสอบตรวจสอบ:
1. **ความถูกต้อง**
   - แปลตรงกับต้นฉบับหรือไม่
   - หลักธรรมถูกต้องหรือไม่
   - ข้อความครบถ้วนหรือไม่

2. **ภาษา**
   - เข้าใจง่ายหรือไม่
   - สละสลวยหรือไม่
   - ถูกต้องตามหลักภาษาหรือไม่

3. **ศัพท์เฉพาะ**
   - ใช้อย่างสม่ำเสมอหรือไม่
   - ถูกต้องหรือไม่
   - เข้าใจง่ายหรือไม่

### 3.3 บันทึกข้อเสนอแนะ
แก้ไขไฟล์ `notes.md`:
```markdown
## จุดที่ต้องแก้ไข
- [ ] บรรทัดที่ 45: เปลี่ยนคำว่า "..." เป็น "..."
- [ ] บรรทัดที่ 120: เพิ่มคำอธิบายศัพท์ "..."

## ข้อเสนอแนะ
- ปรับปรุงภาษาให้สละสลวยขึ้น
- เพิ่มหมายเหตุประกอบสำหรับศัพท์ยาก
```

## ขั้นตอนที่ 4: การอนุมัติ

### 4.1 ส่งให้บรรณาธิการอนุมัติ
1. **สร้าง Pull Request**
```bash
git add .
git commit -m "แปลสัทธรรมปุณฑรีกสูตรเสร็จสิ้น"
git push origin translate/lotus-sutra-54
```

2. **เขียนคำอธิบาย PR**
```markdown
## สิ่งที่แปล
- สัทธรรมปุณฑรีกสูตร (Saddharmapuṇḍarīkasūtram)

## รายละเอียด
- แปลจากต้นฉบับ Romanized text
- รวมศัพท์เฉพาะ 50 คำ
- ตรวจสอบแล้ว 2 รอบ

## หมายเหตุ
- จุดที่ต้องตรวจสอบ: บรรทัดที่ 245-250
```

### 4.2 บรรณาธิการตรวจสอบ
1. อ่านทวนทั้งหมด
2. ตรวจสอบหลักธรรม
3. อนุมัติหรือขอแก้ไข

### 4.3 อนุมัติและ合并
```bash
# หลังจากอนุมัติแล้ว
git checkout main
git merge translate/lotus-sutra-54
```
