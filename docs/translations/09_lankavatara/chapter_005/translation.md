# ลังกาวตารสูตร — บทที่ ๕

## ความเที่ยง/ไม่เที่ยงของตถาคต (Tathāgatanityānityaprasaṅgaparivarto Nāma Pañcamaḥ)

พระมหามติทูลถามถึงพระตถาคตว่า "พระผู้มีพระภาค ตรัสถามว่า ตถาคตเที่ยงหรือไม่เที่ยง?"

พระผู้มีพระภาคตรัสตอบว่า:

> "มหามติ ตถาคตพ้นจากความเที่ยงและไม่เที่ยงทั้งสองฝั่ง"
>
> "ตถาคตไม่ใช่เที่ยง เพราะถ้าเที่ยงก็จะกลายเป็นตาทั่ว (futility) ไม่มีประโยชน์ในการปฏิบัติ ไม่มีกรุณา"
>
> "ตถาคตก็ไม่ใช่ไม่เที่ยง เพราะถ้าไม่เที่ยงก็เหมือนสังขารทั้งปวง คือเกิดดับไป"
>
> "ตถาคตเห็นแจ้งว่าธรรมทั้งปวงไม่เกิด เพราะเป็นเพียงการปรากฏขึ้นของจิต เมื่อเห็นแจ้งอย่างนี้แล้ว ย่อมไม่ยึดมั่นว่าสิ่งใดเที่ยงหรือไม่เที่ยง"

พระองค์ตรัสอีกว่า ความเห็นว่าตถาคตเที่ยงเป็นอุจเฉททิฏฐิ (นอกรอบ) ส่วนความเห็นว่าตถาคตไม่เที่ยงเป็นนัตถิกทิฏฐิ (วัตถุนิยมสุดโต่ง) ตถาคตพ้นจากทิฏฐิทั้งปวง

พระองค์ตรัสเปรียบเทียบด้วยคาถาว่า:

> "ผู้ที่เห็นความไม่เกิด
> เห็นธรรมทั้งปวงเหมือนมายา
> ไม่ติดในเที่ยงและไม่เที่ยง
> ผู้นั้นเห็นตถาคตแท้จริง"
