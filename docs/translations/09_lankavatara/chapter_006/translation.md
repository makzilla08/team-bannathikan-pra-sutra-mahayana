# ลังกาวตารสูตร — บทที่ ๖

## ขณะจิต (Kṣaṇikaparivarto Nāma Ṣaṣṭhaḥ)

### ทฤษฎีขณะจิต

พระผู้มีพระภาคตรัสถึงขณะ (kṣaṇa) หรือ ชั่วขณะหนึ่งของจิต ว่าธรรมทั้งสิ้นเกิดและดับในขณะจิตเดียว (ekakṣaṇa) ไม่มีขณะใดที่ดำรงอยู่ ความเกิดและความดับเป็นเรื่องเดียวกันที่เห็นต่างมุม

### อาลยวิญญาณกับขณะจิต

- **อาลยวิญญาณ**: ไม่ใช่ขณะจิตในความหมายของเกิดดับอย่างวิญญาณอื่น แต่เป็นกระแสต่อเนื่อง ไม่ขาดสาย เปรียบเหมือนแม่น้ำที่ไหลเรื่อย
- **ปวัตรติวิญญาณ 7**: เกิดและดับทุกขณะจิต เปลี่ยนไปตามอารมณ์

### มนัส (Manas) และมโนวิญญาณ (Manovijñāna)

พระองค์ตรัสว่ามนัสคือ วิญญาณที่ยึดมั่นในอาลยวิญญาณ ว่าเป็น "เรา" ส่วนมโนวิญญาณคือผู้คิดปรุงแต่งต่อจากมนัส

### การพ้นจากขณะจิต

เมื่อใดที่สัตว์เห็นแจ้งว่า — 
1. ธรรมภายนอกทั้งปวงเป็นเพียงจิตของตน
2. อาลยวิญญาณเป็นเพียงการไหลเวียนของเมล็ดกรรม
3. เมื่อละเมล็ดกรรมได้หมด สิ้นอาลยวิญญาณ

เมื่อนั้น ย่อมบรรลุธรรมกาย (dharmakāya) ซึ่งพ้นจากขณะจิตทั้งปวง

พระองค์ตรัสว่า:

> "เมื่อตถาคตครรภ์ปราศจากเมล็ดกรรมแห่งอาลยวิญญาณแล้ว ย่อมเป็นธรรมกายที่บริสุทธิ์"
