# สรุปรายชื่อคัมภีร์นิกายโยคาจาร (Digital Sanskrit Buddhist Canon)

คัดสรรและสรุปเนื้อหาจากฐานข้อมูลคัมภีร์พระพุทธศาสนาสันสกฤตดิจิทัล ในส่วนของตำราและคัมภีร์สังกัด **นิกายโยคาจาร (Yogācāra)**

---

## 📋 ภาพรวมและรายชื่อคัมภีร์ (รวม 21 รายการ)

รายชื่อคัมภีร์และตำราที่ปรากฏในระบบ ประกอบด้วยงานประเภทสูตร ศาสตร์ และการิกา (คำกลอนอธิบายปรัชญา) โดยสามารถจำแนกออกเป็นกลุ่มสำคัญได้ดังนี้:

* **กลุ่มคัมภีร์พื้นฐาน (Bhūmi):**
    * *Bodhisattvabhūmiḥ* (โพธิสัตวภูมิ)
    * *Śrāvakabhūmiḥ* (ศราวกภูมิ)
    * *Yogācārabhūmiḥ* (โยคาจารภูมิ)
    * *Smāhitā Bhūmiḥ*
* **กลุ่มตำราหลักและอรรถกถามหายาน (Sūtra & Śāstra):**
    * *Mahāyānasaṃgraha* (มหายานสังคฤหะ)
    * *Madhyāntavibhāga kārikāḥ* (มธยานตวิภังคการิกา)
    * *Mahāyānasūtrālaṃkāraḥ / Mahāyānasūtrālaṃkāraḥ (kārikāḥ)* (มหายานสูตราลังการ)
    * *Ratnagotravibhāgo mahāyānottaratantraśāstram* (รัตนโคตรวิภังค์)
    * *Bodhicittotpādasūtraśāstra*
* **งานเขียนชิ้นเอกด้านวิญญาณวาท (จิตนิยมมหายาน):**
    * *Triṃśikāvijñaptikārikāḥ* (ตรีศิขากาลิกา) - ตำราว่าด้วยวิญญาณ 30 คาถา
    * *Viṃśatikā vijñaptimātratāsiddhiḥ / Viṃśatikākārikā* (วิงศติกะ) - ตำราว่าด้วยจิตมีแต่ข้อพิสูจน์ 20 คาถา
    * *Trisvabhāvanirdeśaḥ* (ไตรสวภาวนิรเทศ) - การอธิบายสภาวะทั้งสาม
* **คัมภีร์ ปกรณ์ และบทนิพนธ์ปรัชญาอื่น ๆ:**
    * *Bāhyarthasiddhikārikānāma*
    * *Bhavasaṅkrāntiparikathā*
    * *Bhavasaṅkrāntiṭīkā*
    * *Cittatatvasaṅgrahaḥ*
    * *Karmavibhaṅgopadeśaḥ*
    * *Pañcaskandhaprakaraṇam* (ปัญจสกันธปกรณ์)
    * *ālokamālā nāma idam*

## 📝 โน้ตสั้นอธิบายเพิ่มเติม (Short Notes)

* **นิกายโยคาจาร (Yogācāra) คืออะไร?**
    * เป็นที่รู้จักกันในชื่อ **"นิกายวิญญาณวาท" (Vijnanavada)** หรือแนวคิดจิตนิยม (Idealism) ของพุทธศาสนามหายาน 
    * เน้นคำสอนที่ว่า *“โลกภายนอกและสิ่งทั้งปวงไม่มีอยู่จริงนอกเหนือไปจากการรับรู้ของจิต”* สิ่งที่เราเห็นเป็นเพียงภาพสะท้อนหรือการแปรเปลี่ยนของวิญญาณ (วิญญัปติมาตร)
    * เป็นหนึ่งในสองเสาหลักปรัชญามหายาน คู่กับ **นิกายมาธยามิก (Madhyamaka)** หรือศูนย์วาท
* **ความสำคัญของคัมภีร์ชุดนี้ในรูปแบบดิจิทัล:**
    * คัมภีร์ภาษาสันสกฤตดั้งเดิมจำนวนมากเคยสูญหายไปจากอินเดีย เหลือรอดเพียงฉบับแปลภาษาจีนและภาษาทิเบต
    * การรวบรวมฉบับสันสกฤต (Digital Sanskrit Buddhist Canon) ช่วยให้นักวิชาการและผู้ศึกษาพระพุทธศาสนา สามารถเข้าถึงตัวบทภาษาดั้งเดิมเพื่อการวิจัย ค้นคว้า และเปรียบเทียบหลักธรรมได้อย่างแม่นยำและสะดวกยิ่งขึ้นผ่านระบบดิจิทัล
