# ทีมบรรณาธิการ - โครงการแปลพระสูตรมหายาน

## วัตถุประสงค์
แปลพระสูตรมหายานจากภาษาสันสกฤต (romanized) เป็นภาษาไทย โดยใช้ข้อมูลจาก Digital Sanskrit Buddhist Canon (DSBC) Project

## เกี่ยวกับโครงการ

โครงการนี้มีเป้าหมายในการแปลพระสูตรมหายานจากภาษาสันสกฤตเป็นภาษาไทย เพื่อให้ชาวไทยสามารถศึกษาพระสูตรมหายานได้สะดวกยิ่งขึ้น โดยใช้ข้อมูลจาก Digital Sanskrit Buddhist Canon (DSBC) Project ซึ่งเป็นโครงการของ University of the West ในการรวบรวมและดิจิทัลไลเซชันพระสูตรพุทธภาษาสันสกฤต

## โครงสร้างโฟลเดอร์

```
team-bannathikan-pra-sutra-mahayana/
├── data/                    # ข้อมูลพระสูตร
│   ├── raw_sutras/         # ไฟล์ดิบจาก DSBC
│   ├── processed/          # ข้อมูลที่จัดรูปแบบแล้ว
│   └── sutra_list.json     # รายการพระสูตรทั้งหมด
├── scripts/                # สคริปต์สำหรับจัดการข้อมูล
│   ├── fetch_sutras.py     # ดึงข้อมูลจาก DSBC
│   └── translation_manager.py  # จัดการงานแปล
├── translations/           # ไฟล์แปลภาษาไทย
├── docs/                   # เอกสารโครงการ
│   ├── team_structure.md   # โครงสร้างทีม
│   ├── translation_guidelines.md  # แนวทางการแปล
│   └── project_plan.md     # แผนโครงการ
└── README.md              # ไฟล์นี้
```

## ทีมงาน

### โครงสร้างทีม
- **บรรณาธิการหลัก** (1 คน): กำกับดูแลคุณภาพการแปลโดยรวม
- **นักแปล** (3-5 คน): แปลพระสูตรจากภาษาต้นฉบับ
- **ผู้ตรวจสอบ** (2-3 คน): ตรวจสอบความถูกต้องของการแปล
- **นักวิชาการ** (1-2 คน): ให้ข้อมูลอ้างอิงทางวิชาการ
- **ผู้จัดการโครงการ** (1 คน): วางแผนและติดตามความคืบหน้า

ดูรายละเอียดเพิ่มเติม: [โครงสร้างทีม](docs/team_structure.md)

## การเริ่มต้น

### ติดตั้ง dependencies
```bash
pip install -r requirements.txt
```

### ดึงรายการพระสูตรจาก DSBC
```bash
python scripts/fetch_sutras.py
```

### สร้างโครงสร้างไฟล์สำหรับงานแปล
```bash
python scripts/translation_manager.py
```

## ขั้นตอนการทำงาน

1. **เตรียมข้อมูล**: ดึงข้อมูลพระสูตรจาก DSBC และจัดรูปแบบ
2. **การแปล**: นักแปลแปลพระสูตรพร้อมบันทึกหมายเหตุ
3. **การตรวจสอบ**: ผู้ตรวจสอบอ่านทวนและให้ข้อเสนอแนะ
4. **การอนุมัติ**: บรรณาธิการหลักตรวจสอบและอนุมัติ

ดูรายละเอียดเพิ่มเติม: [แนวทางการแปล](docs/translation_guidelines.md)

## แหล่งข้อมูล

- **Digital Sanskrit Buddhist Canon (DSBC)**: https://www.dsbcproject.org
- **University of the West**: ผู้พัฒนา DSBC Project
- **Nagarjuna Institute of Exact Method, Nepal**: ผู้ร่วมมือในการเก็บรวบรวมต้นฉบับ

## มาตรฐานคุณภาพ

1. **ความถูกต้อง**: แปลตามความหมายที่แท้จริงของต้นฉบับ
2. **ความชัดเจน**: ใช้ภาษาไทยที่เข้าใจง่าย
3. **ความสละสลวย**: ใช้ภาษาที่สละสลวยเหมาะสมกับพระสูตร
4. **ความสอดคล้อง**: ใช้ศัพท์เทคนิคอย่างสม่ำเสมอ

## การสื่อสาร

- **GitHub Issues**: สำหรับคำถามและข้อสงสัย
- **Pull Requests**: สำหรับเสนอการแปล
- **การประชุมทีม**: ทุกสัปดาห์
