# อภิธานศัพท์ — การัณฑวยูหสูตร (Kāraṇḍavyūha)

| สันสกฤต | ไทย | หมายเหตุ |
|---------|------|----------|
| Kāraṇḍavyūha | การัณฑวยูหสูตร | พระสูตรว่าด้วยการจัดแสดงตะกร้า/หีบ (การัณฑะ) — จัดเป็นไวปุลยสูตรฝ่ายอวโลกิเตศวร |
| Avalokiteśvara | อวโลกิเตศวร | พระโพธิสัตว์ผู้มองลงด้วยความกรุณา — ลังกาเรียก พระนาถ (Nātha), ชวาเรียก อโมฆปาส/โลเกศวร |
| ṣaḍakṣarī mahāvidyā | มหาวิทยาหกอักษร | โอม มณี ปัทเม หูม — หทัยของอวโลกิเตศวร ใจความสำคัญบทที่ 19 |
| Sukhāvatī | สุขาวดี | พุทธเกษตรของพระอมิตาภะ — จุดหมายของผู้ระลึกถึงอวโลกิเตศวร |
| Amitābha | อมิตาภะ | พระธยานิพุทธประจำสุขาวดี — พระบิดาธรรมของอวโลกิเตศวร |
| Jetavana | เชตวัน | อารามของอนาถบิณฑิกเศรษฐี กรุงสาวัตถี — ฉากเปิดเรื่องบทที่ 1 |
| Avīci | อเวจี | มหานรกขุมลึกที่สุด — บทที่ 2 ทำให้อเวจีเหือดแห้งด้วยรัศมีอวโลกิเตศวร |
| Bali | พลิ | จอมอสูรผู้บำเพ็ญยัญ — บทที่ 11 ปลอบโยนพระพลิ |
| Siṃhala | สิงหล | เกาะลังกา — บทที่ 14 เที่ยวสิงหลทวีป โยงอภัยคีรีวิหาร |
| Vārāṇasī | พาราณสี | เมืองพาราณสี — บทที่ 15 |
| Magadha | มคธ | แคว้นมคธ — บทที่ 16 |
| Aśvarāja | อัศวราช | ราชาม้าโพธิสัตว์ — บทที่ 17 อวโลกิเตศวรนิรมิตเป็นม้าช่วยพ่อค้า |
| buddhakṣetra | พุทธเกษตร | แดนของพระพุทธเจ้า — ไม่ใช้ "ศาสนสถาน" |
| dhāraṇī | ธารณี | มนตรายาวสำหรับทรงจำและคุ้มครอง |
| maṇḍala | มณฑล | วงกลมศักดิ์สิทธิ์/ผังจักรวาล — บทที่ 20-22 มณฑลมหาวิทยา |
| vyākaraṇa | พยากรณ์ | พุทธทำนายการตรัสรู้ — บทที่ 23 พระอิศวรได้รับพยากรณ์ |
