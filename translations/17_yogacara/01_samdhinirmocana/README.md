# อารยสังธินิรโมจนสูตร (Āryasaṃdhinirmocana Sūtra)

**Toh 106** | 84000.co — Unraveling the Intent

คัมภีร์รากฐานของนิกายโยคาจาร — อธิบายอาลยวิญญาณ วิชญัปติมาตระ และตฺริสวภาวะ

## โครงสร้างบท

| บทที่ | ชื่อ | สถานะ |
|------|------|--------|
| 1 | นิทานบทที่ ๑ — บทสนทนาของพระโพธิสัตว์ | ✅ แปลแล้ว |
| 2 | นิทานบทที่ ๒ — พระธรรมุทคตะ | ✅ แปลแล้ว |
| 3 | นิทานบทที่ ๓ — พระสุวิศุทธมติ (สัจจะ ๒ ประการ) | ✅ แปลแล้ว |
| 4 | นิทานบทที่ ๔ — พระสุภูติ | ✅ แปลแล้ว |
| 5 | นิทานบทที่ ๕ — พระวิศาลมติ (อาลยวิญญาณ) | ✅ แปลแล้ว |
| 6 | นิทานบทที่ ๖ — พระคุณาการ (ไตรลักษณะ) | ✅ แปลแล้ว |
| 7 | นิทานบทที่ ๗ — พระวิศาลมติ (การปฏิบัติของพระโพธิสัตว์) | ✅ แปลแล้ว |
| 8 | นิทานบทที่ ๘ — พระวิศาลมติ (ความลับแห่งกาย วาจา ใจ) | ✅ แปลแล้ว |
| 9 | นิทานบทที่ ๙ — พระวิศาลมติ (ธรรมแห่งพระอวโลกิเตศวร) | ✅ แปลแล้ว |
| 10 | นิทานบทที่ ๑๐ — พระมัญชุศรี | ✅ แปลแล้ว |
