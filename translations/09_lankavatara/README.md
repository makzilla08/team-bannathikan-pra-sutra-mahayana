# ลังกาวตารสูตร (Laṅkāvatāra Sūtra / 入楞伽經)

## ข้อมูลทั่วไป
- **ชื่อ**: สัทธรรมลังกาวตารสูตร (Saddharmalaṅkāvatārasūtram)
- **ต้นฉบับ**: สันสกฤต
- **ฉบับจีน**: T671 入楞伽經 (Bodhiruci, 513 CE, 10 fascicles)  
- **สถานะ**: แปลเสร็จสมบูรณ์ (10 บท)
- **รหัส**: 09_lankavatara
