# คำศัพท์ - ลังกาวตารสูตร (Laṅkāvatāra Sūtra / 入楞伽經 / T671)

## คำศัพท์เฉพาะ

| สันสกฤต | จีน | ไทย | หมายเหตุ |
|---------|-----|-----|----------|
| laṅkāvatāra | 入楞伽 | ลงกาวตาร | "การเสด็จสู่ลังกา" ชื่อพระสูตร |
| cittamātra | 唯心 | จิตตมาตْر | "ใจเท่านั้น" |
| ālayavijñāna | 阿賴耶識 | อาลยวิญญาณ | วิญญาณพื้นฐาน |
| pravṛttivijñāna | 轉識 | ปวัตรติวิญญาณ | วิญญาณที่หมุนไป |
| tathāgatagarbha | 如來藏 | ตถาคตครรภ์ | ครรภ์แห่งพระตถาคต |
| pañcadharma | 五法 | ปัญจธรรม | 五法: นาม (name), นิมิต (sign), สมมติ (wrong knowledge), สัมยคชญาน (right knowledge), ตรรถ (suchness) |
| trisvabhāva | 三性 | ตริสวภาวะ | สามธรรมชาติ: ปรกัลปิต (imaginary), ปรตนตฺร (dependent), ปรินิษปันน (perfected) |
| aṣṭavijñāna | 八識 | อัษฎวิญญาณ | แปดวิญญาณ |
| nairātmya | 無我 | เนราตมฺย | ความไม่มีอัตตา (ของบุคคลและธรรม) |
| śūnyatā | 空 | ศูนยตา | ความว่าง |
| dharmakāya | 法身 | ธรรมกาย | |
| nirmāṇakāya | 化身 | นิรมาณกาย | |
| svacittadṛśya | 自心所見 | สวจิตตทฤศย | สิ่งที่เห็นด้วยจิตตน |
