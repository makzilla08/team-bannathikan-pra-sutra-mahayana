# Glossary — ไมเตรยพยากรณสูตร

| สันสกฤต | ภาษาไทย | คำอธิบาย |
|----------|---------|----------|
| maitreya | ไมเตรยะ | พระพุทธเจ้าในอนาคต, หมายถึงพระศรีอาริย์ |
| vyākaraṇa | พยากรณ์ | คำทำนาย, การพยากรณ์ในอนาคต |
| śāriputra | สารีบุตร | พระอัครสาวกเบื้องขวา ผู้ทูลถาม |
| ketumatī | เกตุวดี | ชื่อนครในยุคพระไมเตรยะ |
| śaṅkha | ศังขะ | พระนามพระเจ้าจักรพรรดิในยุคนั้น |
| subrahmaṇa | สุพรหมณะ | ปุโรหิตของพระเจ้าศังขะ |
| brahmāvatī | พรหมวดี | มารดาของพระไมเตรยะ |
| nāgavṛkṣa | ต้นนาคะ | ต้นโพธิ์ของพระไมเตรยะ |
| tuṣita | ดุสิต | สวรรค์ชั้นดุสิต ที่ประทับของพระโพธิสัตว์ |
