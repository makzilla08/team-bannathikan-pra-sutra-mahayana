# หมวดสรวาสติวาท (Sarvāstivāda)

คัมภีร์ของนิกายสรวาสติวาท — นิกายสำคัญของพุทธศาสนายุคต้นที่มีอิทธิพลจากอินเดีย แคชเมียร์ คันธาระ นาลันทา และชวา

## หลักคำสอนสำคัญ
- **Sarvāstivāda** (สรรพาสติวาท) = "ทุกสิ่งมีอยู่" — ธรรมทั้งปวงมีอยู่ทั้งในอดีต ปัจจุบัน และอนาคต
- มีระบบอภิธรรมที่ละเอียดที่สุดในบรรดานิกายยุคต้น
- แบ่งธรรมออกเป็น 75 ประเภท (เทียบกับ 82 ของเถรวาท และ ~100 ของมหายาน)

## ประวัติศาสตร์
- เกิดจากสาย Sthavira Nikāya หลังสังคายนาครั้งที่ 2
- ศูนย์กลาง: Mathura → Kashmir (สังคายนาสมัยกนิษกะ) → Gandhara → Nalanda
- แพร่หลายสู่เอเชียกลางและชวา (บันทึกโดยพระอิจิงในศตวรรษที่ 7)
- คัมภีร์สำคัญส่วนใหญ่สูญหายต้นฉบับสันสกฤต แต่คงอยู่ในฉบับแปลจีน

## แหล่งที่มา
- **DSBC** (Digital Sanskrit Buddhist Canon) — ต้นฉบับสันสกฤตที่เหลือรอด
- **Taishō Tripiṭaka** / **CBETA** — ฉบับแปลจีน
- **Tibetan Kangyur / Tengyur** — ฉบับแปลธิเบต
