# อาคม (Āgama) — พระสูตรสายสรวาสติวาท

พระสูตรของสรวาสติวาทมี 4 สาย (Āgama) เทียบเท่า 4 Nikāya ของเถรวาท:

| Āgama | เทียบ Nikāya | เล่มจีน (Taishō) | สถานะสันสกฤต |
|-------|-------------|-----------------|--------------|
| Dīrgha Āgama (ยาว) | Dīgha Nikāya | T1 (長阿含經) | พบ 2/3 ในอัฟกานิสถาน |
| Madhyama Āgama (กลาง) | Majjhima Nikāya | T26 (中阿含經) | สูญหายต้นฉบับสันสกฤต |
| Saṃyukta Āgama (เชื่อม) | Saṃyutta Nikāya | T99 (雜阿含經) | สูญหายต้นฉบับสันสกฤต |
| Ekottara Āgama (เลข) | Aṅguttara Nikāya | T125 (增一阿含經) | สูญหายต้นฉบับสันสกฤต |

## หมายเหตุ
- 4 Āgama นี้เป็นส่วนหนึ่งของ Sūtra Piṭaka ของสรวาสติวาท
- มีพระสูตรเฉพาะที่แตกต่างจาก Nikāya ของเถรวาทบ้าง
- ต้นฉบับสันสกฤตที่เหลือรอดมีเพียงบางส่วน (ส่วนใหญ่จาก Dīrgha Āgama)
- **Mahāprātihāryasūtra** เป็นพระสูตรอิสระที่ DSBC มีในสันสกฤต
