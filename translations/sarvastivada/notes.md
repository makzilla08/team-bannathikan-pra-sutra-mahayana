# บันทึกการทำงาน — หมวดสรวาสติวาท

## แผนการดำเนินงาน
1. สร้างโครงสร้างโฟลเดอร์ ✅
2. โหลดต้นฉบับสันสกฤตจาก DSBC
3. จัดลำดับความสำคัญของคัมภีร์
4. สร้าง Web reader รองรับ
5. เริ่มแปลจากคัมภีร์ที่สำคัญที่สุด

## ข้อสังเกต
- ต้นฉบับสันสกฤตของสรวาสติวาทเหลือรอดน้อยมากเมื่อเทียบกับเถรวาท
- คัมภีร์ส่วนใหญ่ต้องเทียบกับฉบับแปลจีน (Taishō)
- อภิธรรมเป็นจุดเด่นของนิกายนี้ ควรแปลก่อน
- คัมภีร์ Āgama (พระสูตร) ทั้ง 4 สาย ส่วนใหญ่มีเฉพาะในจีน CBETA

## แหล่งค้นคว้าเพิ่มเติม
- Abhidharmakośa ของ Vasubandhu (มีทั้งสันสกฤต แปลจีน แปลธิเบต)
- Mahāvibhāṣā (มหาวิภาษ) — มีเฉพาะแปลจีน 200 ม้วน
- ผลงานของ K. L. Dhammajoti — Sarvāstivāda Abhidharma
