## ความสำคัญ
คัมภีร์อภิธรรมหลักของสรวาสติวาท เดิมชื่อ Aṣṭagrantha (แปดคัมภีร์) เป็นรากฐานของระบบอภิธรรมทั้งหมดของนิกายนี้ มี Mahāvibhāṣā เป็นอรรถกถาอธิบาย
