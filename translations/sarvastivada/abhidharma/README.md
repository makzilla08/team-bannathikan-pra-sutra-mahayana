# อภิธรรม (Abhidharma) — จุดเด่นของสรวาสติวาท

อภิธรรมของสรวาสติวาทเป็นระบบที่ละเอียดและซับซ้อนที่สุดในพุทธศาสนายุคต้น มีการจำแนกธรรมออกเป็น 75 ประเภท และใช้ระบบเหตุผล (hetu) วิเคราะห์ทุกอย่าง

## ลำดับการแปล
1. Abhidharmakośa (คัมภีร์หลักและสำคัญที่สุด)
2. Jñānaprasthāna (คัมภีร์ดั้งเดิมของนิกาย)
3. Abhidharmasamuccaya (เชื่อมกับโยคาจาร)
4. Abhidharmadīpa
5. Mahāvibhāṣā (ถ้ามีต้นฉบับ)
