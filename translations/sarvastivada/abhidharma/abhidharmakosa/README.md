## ความสำคัญ
คัมภีร์อภิธรรมที่สำคัญที่สุดของพุทธอินเดีย สรุปหลักคำสอนของสรวาสติวาท-ไวภาษิก อย่างเป็นระบบ ประกอบด้วย 8 บท:
1. Prathamaṁ kośasthānam — ธาตุ (dhātu)
2. Dvitīyaṁ kośasthānam — อินทรีย์ (indriya)
3. Tṛtīyaṁ kośasthānam — โลก (loka)
4. Caturthaṁ kośasthānam — กรรม (karma)
5. Pañcamaṁ kośasthānam — อนุสัย (anuśaya)
6. Ṣaṣṭhaṁ kośasthānam — มรรคบุคคล (mārga-pudgala)
7. Saptamaṁ kośasthānam — ญาณ (jñāna)
8. Aṣṭamaṁ kośasthānam — สมาธิ (samādhi)
