# วินัย (Vinaya) — ระเบียบสงฆ์ของสรวาสติวาท

นิกายสรวาสติวาทมีวินัยเป็นของตนเอง เรียกว่า **Mūlasarvāstivāda Vinaya** ซึ่งยังคงใช้ในพุทธธิเบตจนถึงปัจจุบัน

| 1 | **Mūlasarvāstivāda-vinayavastu** | คัมภีร์วินัยหลักของมูลสรวาสติวาท — 17 vastu (หมวด) | 91 | ✅ มีต้นฉบับ |
| 2 | **Prātimokṣasūtram** | ปราติโมกษสูตร — ศีลของภิกษุ | 92 | ✅ มีต้นฉบับ |
| 3 | **Bhikṣuṇī vinaya** | วินัยของภิกษุณี | 88 | ✅ มีต้นฉบับ |
| 4 | **Vinaya sūtram** | พระวินัยสูตรรวม | 93 | ✅ มีต้นฉบับ |

## หมายเหตุ
- Mūlasarvāstivāda Vinaya เป็นวินัยที่ใช้ในพุทธธิเบต
- Yijing (อิจิง) บันทึกว่าในชวาและศรีวิชัยศตวรรษที่ 7 ใช้วินัยนี้
- ภิกษุณีวินัยของนิกายนี้สูญไปแล้วในทางปฏิบัติ แต่ต้นฉบับสันสกฤตยังมี
