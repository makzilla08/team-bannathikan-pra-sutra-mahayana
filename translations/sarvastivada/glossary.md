# ศัพท์เฉพาะสรวาสติวาท

## ศัพท์สำคัญ

| สันสกฤต | คำอ่านไทย | ความหมาย |
|---------|-----------|---------|
| sarvāstivāda | สรวาสติวาท | "ทุกสิ่งมีอยู่" — ชื่อนิกาย |
| vaibhāṣika | ไวภาษิก | สาขาหลักของสรวาสติวาท สายแคชเมียร์ |
| sautrāntika | เสาตรานติก | สาขาที่ยึดพระสูตรเป็นหลัก แตกออกมาทีหลัง |
| hetuvāda | เหตุวาท | "วาทะแห่งเหตุ" — ชื่อเรียกอีกอย่างของสรวาสติวาท |
| āgama | อาคม | พระสูตรหมวดต่างๆ |
| abhidharma | อภิธรรม | ธรรมอันยิ่ง หลักคำสอนชั้นสูง |
| vinaya | วินัย | ระเบียบวินัยสงฆ์ |
| tripiṭaka | ตริปิฎก | ตะกร้าสาม หมายถึงคัมภีร์ 3 หมวด |
| kṣaṇika | กษณิก | ขณะจิต — ธรรมเกิดขึ้นแล้วดับในขณะเดียว |
| sarvāstitva | สรวาสติตว | "ความมีอยู่ของทั้งหมด" — ทฤษฎีหลัก |
| dravya | ทรพยะ | สภาวะที่มีอยู่จริง (ultimate reality) |
| prajñapti | ปรัชญปติ | สภาวะสมมติ (conventional designations) |
