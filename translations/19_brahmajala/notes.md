# หมายเหตุ: พรหมชาลสูตร

## จุดที่ต้องตรวจสอบ

- [ ] ตรวจสอบอักษรจีนที่อาจหลงเหลือ
- [ ] ตรวจสอบชื่อพระสาวกให้ถูกต้อง
- [ ] ตรวจสอบสันสกฤตทับศัพท์

## ศัพท์สำคัญ

| สันสกฤต | ไทย | หมายเหตุ |
|---------|-----|----------|
| Brahmajala | พรหมชาละ | ชื่อพระสูตร |
| Bodhisattva | โพธิสัตว์ | ผู้เฒิงชักแสงญาณ |
| Buddhakṣetra | พุทธเกษตร | พระศาสนสถาน |
| Dhāraṇī | ทาโรนี | ระยะหัวมนต์ |
| Lokadhātu | โลกธาตุ | โลกธาตุ |
| Mahāyāna | มหายาน | พระเจ้าแห่งอริยสัจธรรม |
| Pṅña | ปัญญา | ภูมิปัญญา |
| Śūnyatā | ศูนยะ | ความว่างเปล่า |
| Sthavira | สถาวร | ผู้เฒ่า |
| Vinaya | วินยะ | พระเสถียร |

## ข้อสงสัย

- ส่วนเกี่ยวกับโพธิสัตว์สิบหกกิโลกรัม ต้องตรวจสอบความหมายอย่างละเอียด
