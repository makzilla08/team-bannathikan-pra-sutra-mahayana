# คำศัพท์ - พรหมณชาลสูตร (梵網經 / Brahmajāla Sūtra)

## คำศัพท์เฉพาะ

| สันสกฤต | จีน | ไทย | หมายเหตุ |
|---------|-----|-----|----------|
| Brahmajāla | 梵網 | พรหมณชาล | "ตาข่ายแห่งพรหม" ชื่อพระสูตร |
| Vairocana | 毗盧遮那 | พระไวโรจนะ | พระอาทิพุทธะในสูตรนี้ |
| Śākyamuni | 釋迦牟尼 | พระศากยมุนี | พระพุทธเจ้าของเรา |
| bodhisattva | 菩薩 | พระโพธิสัตว์ | |
| prātimokṣa | 波羅提木叉 | ปราติโมกษะ | ศีลใหญ่, ประมวลศีล |
| bodhicitta | 菩提心 | โพธิจิต | จิตแห่งการตรัสรู้ |
| ānantarya | 無間 | อนันตริยะ | กรรมหนักที่ให้ผลไม่ขาดสาย |
| śrāvaka | 聲聞 | พระศราวก | พระสาวก, ผู้ฟัง |
| pratyekabuddha | 緣覺 | พระปัจเจกพุทธเจ้า | |
| mahāyāna | 大乘 | มหายาน | |
| śīla | 戒 | ศีล | |
| pāramitā | 波羅蜜 | บารมี | |
| dhūta | 頭陀 | ธุดงค์ | ข้อปฏิบัติขัดเกลากิเลส |
| prajñā | 智慧 | ปัญญา | |
| śūnyatā | 空 | ความว่าง, สุญญตา | |
| tathāgata | 如來 | ตถาคต | |
| sattva | 眾生 | สัตว์โลก, เวไนยสัตว์ | |
| kauśīdya | 懈怠 | ความเกียจคร้าน | |

## คำศัพท์เฉพาะในพรหมณชาลสูตร

| จีน | ไทย | ความหมาย |
|-----|-----|----------|
| 十發趣心 | จิตมุ่งมั่นสิบ (ทศาอธิมุขจิต) | 10 ข้อแห่งการมุ่งมั่น |
| 十長養心 | จิตหล่อเลี้ยงสิบ (ทศาโปษธจิต) | 10 ข้อแห่งการบำรุง |
| 十金剛心 | จิตวัชระสิบ (ทศวัชรจิต) | 10 ข้อแห่งจิตแข็งดุจเพชร |
| 十地 | ภูมิสิบ (ทศภูมิ) | 10 ระดับแห่งการบรรลุ |
| 十重波羅提木叉 | ศีลหนักสิบ (ทศปราติโมกษะ) | ปาราชิกของโพธิสัตว์ |
| 四十八輕戒 | ศีลเบาสี่สิบแปด (จตุราสีติกาล) | ศีลรอง 48 ข้อ |
