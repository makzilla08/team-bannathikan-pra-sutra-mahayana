# สัทธรรมปุณฑรีกสูตร
# คัมภีร์ดอกบัวขาวแห่งธรรมอันดี

## บทที่ ๒๗ — การมอบฝาก (อนุปริณฺทนาปริวรรต)

ก็โดยสมัยนั้นแล พระผู้มีพระภาคศากยมุนีตถาคต ผู้เป็นพระอรหันต์ ตรัสรู้โดยชอบเอง ทรงลุกจากธรรมาสน์นั้น ทรงรวบรวมพระโพธิสัตว์ทั้งหมด ทรงประคองด้วยพระหัตถ์เบื้องขวาอันสำเร็จด้วยอธิษฐานแห่งฤทธิ์ ทรงประคองที่พระหัตถ์เบื้องขวาของพระโพธิสัตว์เหล่านั้น แล้วตรัสในเวลานั้นว่า

*"ดูก่อนกุลบุตรทั้งหลาย เรามอบหมาย มอบฝาก วางลง ประดิษฐานไว้ซึ่งอนุตรสัมมาสัมโพธินี้อันเราสั่งสมมาตลอดกัปหาประมาณมิได้ โกฏิแสน ซึ่งไว้ในมือของพวกเธอ เพื่อที่ธรรมนี้จักกว้างขวางไพศาล พวกเธอพึงกระทำอย่างนั้น"*

แม้ครั้งที่สองและครั้งที่สาม พระผู้มีพระภาคก็ทรงประคองพระหัตถ์เบื้องขวาที่หมู่พระโพธิสัตว์ทั้งปวงแล้วตรัสว่า

*"ดูก่อนกุลบุตรทั้งหลาย เรามอบหมาย มอบฝาก วางลง ประดิษฐานไว้ซึ่งอนุตรสัมมาสัมโพธินี้อันเราสั่งสมมาตลอดกัปหาประมาณมิได้ โกฏิแสน ไว้ในมือของพวกเธอ พวกเธอพึงถือไว้ พึงทรงจำไว้ พึงอ่านไว้ พึงรู้จบไว้ พึงแสดงไว้ พึงประกาศไว้ และพึงให้สัตว์ทั้งปวงได้ฟัง*

*ดูก่อนกุลบุตรทั้งหลาย เราเป็นผู้ไม่ตระหนี่ มีจิตไม่ยึดติด เป็นผู้กล้าให้พุทธญาณ เป็นผู้ให้ตถาคตญาณ เป็นผู้ให้สยัมภูญาณ เราเป็นมหาทานบดีดูก่อนกุลบุตรทั้งหลาย พวกเธอก็จงศึกษาตามเราเถิด*

*เมื่อไม่ตระหนี่แล้ว พึงให้ธรรมปริยายนี้ คือ ความเห็นญาณของพระตถาคต อันเป็นมหาอุปายเกาศัลย์ แก่กุลบุตรและกุลธิดาผู้มาถึงแล้ว และพึงให้สัตว์ที่ยังไม่มีศรัทธาให้สมาทานในธรรมปริยายนี้*

*ดูก่อนกุลบุตรทั้งหลาย เมื่อพวกเธอกระทำอย่างนี้ จักเป็นการตอบแทนพระคุณของพระตถาคตทั้งหลาย"*

เมื่อพระผู้มีพระภาคศากยมุนีตถาคต ผู้เป็นพระอรหันต์ ตรัสรู้โดยชอบเอง ตรัสอย่างนี้แล้ว พระโพธิสัตว์มหาสัตว์เหล่านั้นก็เต็มเปี่ยมด้วยความปราโมทย์และปีติอย่างยิ่ง เกิดความเคารพอย่างสูง ต่างน้อมกาย น้อมกายลง โน้มกายลง ก้มศีรษะ ประนมมือ แล้วทั้งหมดกล่าวเป็นเสียงเดียวกันถวายพระพรพระผู้มีพระภาคศากยมุนีตถาคต ผู้เป็นพระอรหันต์ ตรัสรู้โดยชอบเอง ว่า

*"ข้าแต่พระผู้มีพระภาค พวกข้าพระองค์จักกระทำตามที่พระตถาคตทรงบัญชา จักกระทำตามคำสั่งของพระตถาคตทั้งปวง จักทำให้บริบูรณ์ ขอพระผู้มีพระภาคทรงเป็นผู้มีความกังวลน้อย ทรงอยู่อย่างสุขสบายเถิด"*

แม้ครั้งที่สองและครั้งที่สาม หมู่พระโพธิสัตว์ทั้งปวงก็กล่าวเป็นเสียงเดียวกันว่า

*"ขอพระผู้มีพระภาคทรงเป็นผู้มีความกังวลน้อย ทรงอยู่อย่างสุขสบายเถิด ข้าแต่พระผู้มีพระภาค พวกข้าพระองค์จักกระทำตามที่พระตถาคตทรงบัญชา จักทำให้บริบูรณ์ซึ่งคำสั่งของพระตถาคตทั้งปวง"*

ครั้งนั้น พระผู้มีพระภาคศากยมุนีตถาคต ผู้เป็นพระอรหันต์ ตรัสรู้โดยชอบเอง ทรงส่งพระตถาคตทั้งปวง ผู้เป็นพระอรหันต์ ตรัสรู้โดยชอบเอง ผู้มาจากโลกธาตุอื่น ให้เสด็จกลับ และทรงบอกความอยู่สุขสบายแก่พระตถาคตเหล่านั้นว่า *"พระตถาคตทั้งหลาย ผู้เป็นพระอรหันต์ ตรัสรู้โดยชอบเอง จงอยู่โดยสุขสบายเถิด"*

และทรงตั้งพระสถูปแก้วของพระผู้มีพระภาคปฺรภูตรัตนตถาคต ผู้เป็นพระอรหันต์ ตรัสรู้โดยชอบเอง ไว้ในภูมิประเทศดังเดิม และทรงบอกความอยู่สุขสบายแก่พระตถาคตพระองค์นั้นด้วย

พระผู้มีพระภาคตรัสคำนี้แล้วทรงเบิกบานพระทัย พระตถาคตทั้งหลายผู้เป็นพระอรหันต์ ตรัสรู้โดยชอบเอง อันประมาณมิได้ นับไม่ถ้วน ผู้มาจากโลกธาตุอื่น ซึ่งประทับนั่งบนบัลลังก์สิงห์ภายใต้ต้นรัตนพฤกษ์ พระปฺรภูตรัตนตถาคต ผู้เป็นพระอรหันต์ ตรัสรู้โดยชอบเอง และหมู่พระโพธิสัตว์ทั้งปวงนั้น รวมทั้งพระโพธิสัตว์มหาสัตว์ผู้มีพระจริยาวิเศษเป็นต้น อันประมาณมิได้ นับไม่ถ้วน ผู้โผล่ขึ้นจากช่องแผ่นดิน และพระมหาสาวกเหล่านั้น และบริษัทสี่ พร้อมทั้งโลกเทวา มนุษย์ อสูร คนธรรพ์ ต่างชื่นชมยินดีในพระภาษิตของพระผู้มีพระภาค
