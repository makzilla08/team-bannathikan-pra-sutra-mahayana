# หมายเหตุ: บทที่ 25 - สรรพสัตว์ปะริปากะคุณตสาทะศรีเทวี (Sarvasattvaparipākaguṇotsadaśrī)

## จุดที่ต้องตรวจสอบ

- [x] ตรวจสอบลำดับบท: ในฉบับ DSBC เทพธิดาองค์นี้ปรากฏในส่วนท้ายของเทพธิดาเจ้าราตรี (ประมาณลำดับที่ 34 ในรายชื่อ 53 กัลยาณมิตร) แต่ในโครงสร้างโครงการนี้กำหนดให้เป็นบทที่ 25
- [x] ตรวจสอบชื่อเทพธิดา: ในต้นฉบับบางส่วนอาจใช้ชื่อว่า *สรวชคัทรักศาประณิธานวีรยประภา* (Sarvajagadrakṣāpraṇidhānavīryaprabhā) ซึ่งมีวิโมกข์เกี่ยวกับการบ่มเพาะสัตว์ (Sarvasattvaparipāka) เช่นเดียวกัน

## ศัพท์สำคัญในบทนี้

| สันสกฤต | ไทย | หมายเหตุ |
|---------|-----|----------|
| Bodhimaṇḍa | โพธิมณฑล | สถานที่ตรัสรู้/ธรรมศาลา |
| Rātridevatā | เทพธิดาเจ้าราตรี | เทวดาผู้ดูแลเวลากลางคืน |
| Sarvasattvaparipāka | การบ่มเพาะสรรพสัตว์ | การทำให้กุศลมูลของสัตว์โลกสุกงอม |
| Vimokṣa | วิโมกข์ | ความหลุดพ้น/ธรรมบรรลุ |
| Vijitāvin | วิชิตาวิน | นามของพระโพธิสัตว์ในอดีตชาติ |
