# คัณฑวยูหะสูตร (Gaṇḍavyūha Sūtra)

## ข้อมูลพระสูตร
- **ชื่อบาลี/สันสกฤต:** Gaṇḍavyūha Sūtra
- **ชื่อไทย:** คัณฑวยูหะสูตร (กัณฑวิภังคสูตร)
- **แหล่งที่มา:** Digital Sanskrit Buddhist Canon (DSBC) - ID 40
- **ความสำคัญ:** เป็นส่วนสุดท้ายของ "อวตังสกสูตร" (Avataṃsaka Sūtra) ว่าด้วยการเดินทางแสวงหาโมกขธรรมของสุธนกุมาร
- **ตัวละครหลัก:** สุธนกุมาร (Sudhana Kumāra), พระมัญจุศรีโพธิสัตว์, พระสมันตภัทรโพธิสัตว์
