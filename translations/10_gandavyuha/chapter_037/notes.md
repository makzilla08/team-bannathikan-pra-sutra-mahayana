# บันทึกการแปล: บทที่ 37 - สมันตสัตตวตราโณชศรีราตรีเทวี (samantasattvatrāṇojaḥśrīḥ)

## ประเด็นสำคัญ
- สมันตสัตตวตราโณชศรีราตรีเทวีเป็นครูท่านที่ 37 ของสุธนกุมาร
- ได้สัพพโลกาภิมุขชควินายนทรรศนะโพธิสัตว์วิโมกข์
- แสดงโลกธาตุในปรมาณูแต่ละปรมาณู เห็นสัตว์ในคติต่างๆ
- เรื่องอดีตชาติ: เป็นธิดาแห่งจักรพรรดิชื่อปัทมภทราภิรามเนตรศรีจันทรา
- จักรพรรดิไวโรจนรัตนปัทมครรภศรีจูฑะคือไมตรีย์โพธิสัตว์ในอดีต
- มเหสีสัมปูรณศรีวakraคือประศานตรุตสาครวดีราตรีเทวี (ครูท่านที่ 38)
- บูชาพระพุทธเจ้ามาแล้วมากมายหลายร้อยพระองค์ในกัลป์ต่างๆ
- แนะนำให้ไปพบประศานตรุตสาครวดีราตรีเทวี

## ศัพท์ใหม่
- samantasattvatrāṇojaḥśrīḥ = สมันตสัตตวตราโณชศรี
- sarvalokābhimukhajagadvinayanidarśana = สัพพโลกาภิมุขชควินายนทรรศนะ
- atyantavirajomaṇḍala = อัตยันตวิรโชรมณฑล (สมาธิ)
- vairocanaratnapadmagarbhaśrīcūḍa = ไวโรจนรัตนปัทมครรภศรีจูฑะ
- saṃpūrṇaśrīvakrā = สัมปูรณศรีวakra
- padmabhadrābhirāmanetraśrī = ปัทมภทราภิรามเนตรศรี
- samantajñānārciśrīguṇaketudhvaja = สมันตชานarciศรีคุณเกตุธวัช
- ratnakusumapradīpadhvaja = รัตนกุมุสปประทีปธวัช
- praśāntarutasāgaravatī = ประศานตรุตสาครวดี
- dharmadhātunayāvartagarbha = ธรรมธาตุนายาวรรตครรภ

## หมายเหตุ
- บทนี้เป็นการพบครูท่านที่ 37
- บทสำคัญมาก มีเรื่องอดีตชาติและคาถา 58 บท
- จบด้วยการชี้ทางไปพบประศานตรุตสาครวดีราตรีเทวี (บทที่ 38)
