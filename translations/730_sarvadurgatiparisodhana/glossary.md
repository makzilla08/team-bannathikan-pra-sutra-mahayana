# อภิธานศัพท์ — สรวทุรคติปริโศธนตันตระ (Sarvadurgatipariśodhana)

|---------|------|----------|
| Sarvadurgatipariśodhana | สรวทุรคติปริโศธนะ | การชำระทุรคติทั้งปวง — ชื่อตันตระและสมาธิ |
| śrīvajrasattva | ศรีวัชรสัตว์ | พระวัชรสัตว์ — พระประธานในคำนมัสการ |
| devendra | เทเวนทระ | ท้าวสักกะ/พระอินทร์ — ผู้ทูลถาม |
| Vimalamaṇiprabha | วิมลมณิประภะ | เทพบุตรผู้ตกอเวจี — กรณีศึกษาเรื่องทุรคติ |
| Avīci | อเวจี | มหานรกขุมลึกที่สุด |

| tathāgata | ตถาคต | ผู้เสด็จมาแล้ว |
