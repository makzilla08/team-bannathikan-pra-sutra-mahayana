# ตอนที่ 5/89: ธารณีหลัก

พระผู้มีพระภาคเปล่งธารณีหลัก — โอม โศธเน โศธเน สรรวปาปวิโศธนิ ศุทเธ วิศุทเธ สรรวกรมมาวรณวิศุทเธ สวาหา — สรรพสัตว์พ้นจากทุรคติ
