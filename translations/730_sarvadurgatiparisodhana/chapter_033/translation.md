# ตอนที่ 33/89: ธรรมเทศนา

พระผู้มีพระภาคตรัสธรรมเพื่อชำระทุรคติทั้งปวง แสดงอานิสงส์การสวด การสร้างมณฑล และการบูชา เพื่อประโยชน์แก่สัตว์ทั้งปวง
