# หมายเหตุ: วิมลกีรตินิเทศสูตร

## คำศัพท์เฉพาะ

| สันสกฤต | ไทย | หมายเหตุ |
|---------|-----|----------|
| āmrapālīvana | สวนอัมรปานี | สวนของนางบำเรอผู้ถวายแด่พระพุทธเจ้า |
| vaiśālī | เวสาลี | เมืองหลวงของลิจฉวี ปัจจุบันคือ Vaishali ในอินเดีย |
| licchavi | ลิจฉวี | ตระกูลกษัตริย์ครองเวสาลี |
| ratnākara | รัตนัคระ | หนุ่มน้อยลิจฉวี แปลว่า "ผู้มีสมบัติมาก" |
| simhāsana | สีหอาสนะ | บัลลังก์ราชสีห์ |
| ratnacchatra | รัตนฉัตร | ร่มแก้ว ร่มมุกดาหาร ถวายเป็นเครื่องบูชา |
| prātihārya | ปฏิหาริย์ | ปาฏิหาริย์ อิทธิฤทธิ์ |
| trisāhasramahāsāhasra | สามพันมหาสังสาลิกะ | หน่วยวัดจักรวาลในพระพุทธศาสนา |
| buddhakṣetra | **พุทธเกษตร** | แดนพระพุทธเจ้า (ศัพท์มหายาน) |
| śāriputra | สารีบุตร | พระสาวกผู้เลิศปัญญา |

## จุดที่ต้องตรวจสอบ

- [x] ศัพท์ "buddhakṣetra" แปลว่า "พุทธเกษตร" ไม่ใช่ "ศาสนสถาน" - แก้ไขแล้ว
- [ ] วรรคที่ยาวมาก ควรปรับภาษาให้กระชับ
- [ ] คาถาสรรเสริญ (บทที่ 7) ควรจัดรูปแบบให้สวยงาม
- [ ] คำว่า "deva 寅" - ใช้คำว่า "เทพยดา" หรือ "เทพ" อย่างไรให้สอดคล้อง
- [ ] ชื่อภูเขาต่างๆ - ใช้รูปไทยหรือสันสกฤต

## ข้อสงสัย

1. **วรรค 1** - รายชื่อพระโพธิสัตว์จำนวนมาก ต้องการรายชื่อที่ถูกต้อง
2. **วรรค 5** - คำว่า "trisāhasramahāsāhasralokadhātu" มีหลายรูปแบบแปล ควรใช้รูปไหน
3. **วรรค 9** - "brahmā śikhin" แปลว่า "พรหมศิกขิน" หรือ "พรหมศิขร"

## บันทึกการแปล

### บทที่ 1: พุทธเกษตรบริสุทธิ์

**วันที่**: 2026-03-18
**สถานะ**: แปลปรับปรุง (revised)

**ประเด็นสำคัญของบทที่ 1**
1. **พุทธเกษตรบริสุทธิ์** - พระพุทธเจ้าแสดงว่าพุทธเกษตรบริสุทธิ์เสมอ แต่สัตว์ที่มีจิตไม่บริสุทธิ์ไม่เห็น
2. **ปาฏิหาริย์ร่มแก้ว** - แสดงอำนาจแห่งพระพุทธเจ้า ร่มแก้วเดียวปกคลุมโลกธาตุทั้งหมด
3. **จิตสร้างพุทธเกษตร** - "จิตบริสุทธิ์ พุทธเกษตรก็บริสุทธิ์" เป็นหลักสำคัญของพระสูตรนี้

**การปรับปรุง**
- เปลี่ยนคำแปล "buddhakṣetra" จาก "ศาสนสถาน" เป็น "พุทธเกษตร" (ศัพท์มหายานที่ถูกต้อง)
- ปรับสำนวนแปลให้สละสลวยขึ้น
- ปรับปรุง glossary เพิ่มคำศัพท์มหายาน

### บทที่ 2: วิธีอันอัศจรรย์

**วันที่**: 2026-03-18
**สถานะ**: แปลปรับปรุง (revised)

**ประเด็นสำคัญของบทที่ 2**
1. วิมลกีรติเป็นตัวอย่างคฤหัสถ์ผู้ปฏิบัติดี
2. อุบายแสดงตนป่วยเพื่อให้ผู้คนมาฟังธรรม
3. กายเป็นปฏิจจสมุปบาท ไม่เที่ยง ไม่ใช่ตัวตน
4. ธรรมกายแห่งพระตถาคตเกิดจากบุญและปัญญา

## ปัญหาในการแปล

- สันสกฤตในพระสูตรนี้ยาวมาก บางวรรคมีหลายสิบคำ
- ต้องแบ่งวรรคใหม่เพื่อให้อ่านง่าย
- คาถาสรรเสริญต้องจัดรูปแบบใหม่

## บันทึกการแปล - บทที่ 4

**วันที่**: 2026-03-18
**สถานะ**: แปลเสร็จ

### ประเด็นสำคัญของบทที่ 4
1. **โรคแห่งกิเลส**: ความโลภ โกรธ หลง คือโรคที่แท้จริง
2. **ไตรสรณคมน์เป็นยา**: พระพุทธ พระธรรม พระสงฆ์ คือผู้รักษา
3. **ความว่างจากตัวตน**: ผู้รู้แจ้งความว่าง จิตไม่ป่วยแม้กายจะป่วย
4. **พระมัญจุศรี**: โพธิสัตว์ผู้เลิศปัญญา อาสาไปเยี่ยมวิมลกีรติ

### ข้อควรปรับปรุง
- บทสนทนาอาจสั้นเกินไป ควรตรวจสอบต้นฉบับจีน/ทิเบต
- เพิ่มรายละเอียดการสนทนาเรื่องกาย

## บันทึกการแปล - บทที่ 5

**วันที่**: 2026-03-18
**สถานะ**: แปลเสร็จ

### ประเด็นสำคัญของบทที่ 5
1. **วิมลกีรติแสดงสมาธิ**: แสดงด้วยฤทธิ์ ไม่ใช่ด้วยวาจา
2. **พุทธเกษตรปรากฏ**: โลกธาตุเปลี่ยนเป็นพุทธเกษตรบริสุทธิ์
3. **อุปมาคนตาบอด**: จิตมืดมน ไม่เห็นพุทธเกษตร (เหมือนคนตาบอดไม่เห็นดวงอาทิตย์)
4. **พระพุทธเจ้าเหยียบแผ่นดิน**: แสดงปาฏิหาริย์ยืนยันพุทธเกษตรบริสุทธิ์
5. **ผลสมาธิ**: ผู้มาเยี่ยมจำนวนมากเกิดจิตเพื่อพระสัมมาสัมโพธิญาณ
