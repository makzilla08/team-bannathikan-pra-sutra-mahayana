# หมวดมัธยมกะ (Mādhyamaka)

คัมภีร์ปรัชญาสายมัธยมกะ (Mādhyamaka) — นิกายที่ก่อตั้งโดยพระนาคารชุน (Ācārya Nāgārjuna) ว่าด้วยสุญญตา (śūnyatā) ปฏิจจสมุปบาท และมธยมาการิกา

## หลักคำสอนสำคัญ
- **สุญญตา (śūnyatā)** = ความว่างเปล่าจากการมีอยู่โดยตัวตน (svabhāva)
- **สองสัจจะ**: สมมติสัจจะ (saṃvṛtisatya) กับ ปรมัตถสัจจะ (paramārthasatya)
- **ปฏิจจสมุปบาท** = เหตุปัจจัยที่อาศัยกันและกัน ไม่มีสิ่งใดเกิดโดยอิสระ
- คัมภีร์มธยมากการิกาเป็นรากฐาน → มีอรรถกถาของพระจันทรีกีรติ (Prasannapadā) และพระภาววิเวก (Prajñāpradīpa)

## ประวัติศาสตร์
- **พระนาคารชุน** (ศตวรรษที่ 2) — ผู้ก่อตั้งนิกาย, ประพันธ์ Mūlamadhyamakakārikā, Vigrahavyāvartanī, Śūnyatāsaptatiḥ, Yuktiṣaṣṭikārikā
- **พระอารยะเทวะ** (ศตวรรษที่ 3) — ลูกศิษย์สำคัญ, ประพันธ์ Catuḥśatikā
- **พระจันทรีกีรติ** (ศตวรรษที่ 7) — อรรถกถา Prasannapadā และ Madhyamakāvatāra
- **พระภาววิเวก** (ศตวรรษที่ 6) — สายสวาตันตริก, Prajñāpradīpa
