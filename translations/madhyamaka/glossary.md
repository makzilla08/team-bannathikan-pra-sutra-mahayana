# ศัพท์มัธยมกะ

## ศัพท์หลัก
| สันสกฤต | ไทย | หมายเหตุ |
|-----------|------|----------|
| mādhyamaka | มัธยมกะ | สายกลาง |
| śūnyatā | สุญญตา | ความว่างเปล่า |
| svabhāva | สวภาวะ | การมีอยู่โดยตัวตน |
| pratītyasamutpāda | ปฏิจจสมุปบาท | เกิดขึ้นโดยอาศัยกัน |
| saṃvṛtisatya | สมมติสัจจะ | สัจจะเชิงสมมติ/โลกวิสัย |
| paramārthasatya | ปรมัตถสัจจะ | สัจจะสูงสุด |
| dharmatā | ธรรมตา | สภาพธรรม |
| tathatā | ตถตา | ความเป็นเช่นนั้น |
| nirvāṇa | นิพพาน | ความดับ |
| saṃsāra | สังสารวัฏ | การเวียนว่ายตายเกิด |
| madhyamā pratipad | มัชฌิมาปฏิปทา | ทางสายกลาง |
