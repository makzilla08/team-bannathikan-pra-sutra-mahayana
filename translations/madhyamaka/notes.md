# บันทึกหมวดมัธยมกะ

## 2026-08-19
- สร้างหมวด madhyamaka/ จากลิสต์ DSBC 64 (มัธยมกะ, 28 เล่ม) และลิสต์ 65 (มัธยมกะ-โยคาจาร, 16 เล่ม)
- ดาวน์โหลดต้นฉบับทั้งหมดเพื่อเตรียมแปล
- คัมภีร์สำคัญที่ต้องให้ความสำคัญก่อน: มูลมัธยมากการิกา (931), วิเคราะห์วยวรตน์ (254), ศูนยตาสัปตติ (252), จตุหศตกา (237), มัธยมกาวตาร (243/852/887), ปราสันนปทา (247), โพธิจริยาวตาร (258)

## ข้อสังเกต
- ลิสต์ 64 รายการ 24, 26, 27, 28 เป็น Pratītyasamutpādastutisubhāṣitahṛdayam ฉบับซ้ำ (896, 962, 963, 970) — อาจแยกตามสำนักพิมพ์/ต้นฉบับ ควรเทียบเนื้อหาก่อนแปล
- ลิสต์ 65 รวมคัมภีร์สาย Bodhisattva path (Bhāvanākrama, Bodhicaryāvatāra, Śikṣāsamuccaya) ที่เป็นจุดเชื่อมระหว่างมัธยมกะกับโยคาจาร
